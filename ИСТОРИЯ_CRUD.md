## 🔧 Как работает

### 1. Пользователь нажимает кнопку "✕"
```javascript
<button class="delete-btn" onclick="deleteCalculation('id')">
    ✕
</button>
```

### 2. Появляется подтверждение
```
┌─────────────────────────────────┐
│ Вы уверены, что хотите удалить  │
│ эту запись из истории?          │
│                                  │
│  [ Отмена ]   [ ОК ]            │
└─────────────────────────────────┘
```

### 3. При подтверждении
- 🌐 Отправляется DELETE запрос на сервер
- 💾 Запись удаляется из PostgreSQL
- ✨ Плавная анимация (запись уходит вправо)
- 🔄 Автоматическое обновление списка истории

## 📡 API

### DELETE /calculations/{id}
Удаляет расчет по ID

**Request:**
```http
DELETE /calculations/{id}
Authorization: Bearer {token}
```

**Response (успех):**
```json
{
  "message": "Calculation deleted"
}
```

**Response (ошибка):**
```json
{
  "error": "Calculation not found"
}
```

    // Подтверждение

        return;
    }
    
    // DELETE запрос
    const response = await fetch(
        `${API_URL}/calculations/${calculationId}`,
        {
            method: 'DELETE',
            headers: {
                'Authorization': `Bearer ${token}`
            }
        }
    );
    
    if (response.ok) {
        // Анимация + обновление списка

}
